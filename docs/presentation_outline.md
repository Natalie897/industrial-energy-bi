# Презентация проекта для работодателя — структура 6 слайдов

1. **Problem & Goal:** руководителю нужна прозрачная картина энергопотребления; учебные бизнес-гипотезы.
2. **Source:** CSV с 15-минутными измерениями, ограничения (нет цехов и фактических тарифов), два режима demo/UCI.
3. **Architecture:** CSV → ETL/DQ → Staging → DWH Star Schema → BI.
4. **Model & SQL:** fact, dim_date/time/load, один сложный SQL-запрос с `LAG`.
5. **Dashboard:** скриншоты трёх страниц, фильтрация, показатель расходов явно модельный.
6. **QA & Next Steps:** тесты, сверка, план инкрементальной загрузки и полноценного промышленного внедрения.

Презентацию можно сделать в PowerPoint по этому плану; готовый `.pptx` в архив не включён.

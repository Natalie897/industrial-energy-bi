# Описание проекта для резюме и собеседования

## Название

**Industrial Energy Analytics — BI/DWH-система анализа энергопотребления промышленного предприятия**

## Краткое описание для резюме

Разработала учебный end-to-end BI-проект для анализа промышленного энергопотребления: сформулировала бизнес-требования и критерии приёмки, спроектировала витрину DWH по схеме «звезда», реализовала ETL на Python с валидацией качества, написала SQL-запросы (JOIN, CTE, оконные функции), подготовила интерактивный дашборд и тест-кейсы. Реализовала локальную SQLite-модель, SQL DDL и загрузчик для PostgreSQL; подготовила Power BI CSV-модель и DAX-меры.

**Стек:** SQL, SQLite/PostgreSQL, Python, pandas, Plotly, Streamlit, Power BI (модель + DAX), GitHub.

## Краткий рассказ на интервью (45–60 секунд)

«Я сделала учебный BI-кейс для энергетической аналитики металлургического предприятия. Начала с постановки бизнес-вопросов и составления документа с требованиями и критериями приёмки. Затем разработала модель хранилища: факт — 15-минутное измерение, измерения — дата, время и тип нагрузки. Написала ETL с проверкой дублирования timestamp, корректности календарных признаков и баланса сумм. Подготовила SQL-аналитику с оконными функциями и три экрана дашборда. Дополнительно написала тест-кейсы и DAX-меры для Power BI. Для воспроизводимой офлайн-демонстрации включила синтетический набор данных; код поддерживает замену на оригинальный набор UCI».

## Как показать проект за 3 минуты

1. Показать README и сформулировать бизнес-проблему (20 с).
2. Показать BRD: один вопрос и критерий приёмки (20 с).
3. Открыть `docs/data_dictionary.md`: объяснить зерно факта и 3 измерения (40 с).
4. Открыть `dashboard/report.html`: фильтр месяца, тип нагрузки, тепловая карта, модель расходов (60 с).
5. Показать `sql/01_analytics.sql`: CTE + LAG + JOIN (30 с).
6. Показать `tests/test_etl.py`: дубли и сверка, ограничения проекта (30 с).
